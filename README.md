# xelastarburst.github.io

Alex Qi's portfolio, live at https://xelastarburst.github.io

One static page. `index.html` holds the markup, styles and script; images and fonts are in `assets/`, named with a content hash. Videos play through YouTube's privacy-enhanced embed. `og.jpg` is the link-preview image, and `404.html` sends stray URLs back to the home page.
